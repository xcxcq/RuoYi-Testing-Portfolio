# [BUG-01] 允许隐藏超级管理员核心菜单，导致前端路由死锁，无法通过 UI 恢复

## 📌 基本信息
- **缺陷编号**：BUG-01
- **所属模块**：系统管理 - 菜单管理
- **严重程度**：严重 (Major) - 导致功能阻断
- **测试环境**：Windows 10 / Chrome 浏览器 / 若依分离版 (本地部署)

## 📝 前置条件
使用超级管理员 `admin` 账号登录系统。

## 🔁 复现步骤
1. 进入左侧导航栏【系统管理】 -> 【菜单管理】。
2. 找到名称为“系统管理”的目录，点击右侧的【编辑】。
3. 将“可见”状态由“显示”修改为“隐藏”，点击【确定】保存。
4. 刷新浏览器页面。

## ❌ 实际结果
1. 左侧导航栏中的“系统管理”目录及其所有子菜单消失。
2. 尝试通过浏览器地址栏直接输入路由 `http://localhost/system/menu` 强制访问，被前端路由守卫拦截，提示 403 或跳转首页。
3. 由于无法进入菜单管理界面，管理员无法通过正常的 UI 途径将其恢复，系统进入死锁状态（只能通过连接后台数据库修改 `visible` 字段来强制修复）。

## ✅ 预期结果
1. 系统应具备“防呆机制”，**拦截对核心管理模块（系统管理、菜单管理、角色管理等）的隐藏或删除操作**。
2. 或者，对于超级管理员（admin），前端路由不应受到“可见性”字段的强制拦截，确保管理员永远有权限找回入口。
