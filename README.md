# 若依（RuoYi）后台管理系统 测试实战项目

本项目基于国内主流开源后台管理系统“若依（前后端分离版）”进行全流程测试实战。涵盖手工功能测试、接口安全测试及 Python+Pytest 自动化测试，旨在验证系统的 RBAC 权限模型及前后端数据交互逻辑。

## 🛠️ 技术栈与工具
- **测试类型**：功能测试、接口测试、安全越权测试、边界值/异常测试
- **测试工具**：F12 开发者工具、Apifox、MySQL
- **自动化技术栈**：Python 3.10、Pytest、Requests、pytest-html
- **文档管理**：Markdown、Excel

## 📂 项目产出目录
- 📄 [01_Test_Plan (测试计划)](./01_Test_Plan/)：明确测试范围、策略与环境。
- 📊 [02_Test_Cases (测试用例)](./02_Test_Cases/)：包含登录、用户管理、安全模块等核心用例。
- 🐛 [03_Bug_Reports (缺陷报告)](./03_Bug_Reports/)：记录并规范输出了“权限死锁”、“外链防呆缺失”等有效缺陷。
- 💻 [04_Automation_Code (自动化代码)](./04_Automation_Code/)：基于 Pytest 的接口自动化脚本。
- 📈 [05_Test_Report (自动化报告)](./05_Test_Report/)：自动化用例执行后的 HTML 可视化报告。

## 🚀 核心测试成果摘要
1. **权限体系深度测试**：验证了若依系统“用户-角色-菜单”的 RBAC 模型。通过配置隐藏菜单，发现并验证了前端路由守卫的拦截机制，发现了“核心菜单隐藏导致路由死锁”的严重缺陷。
2. **接口安全防御验证**：使用 Apifox 与 Python 脚本，伪造普通用户 Token 尝试垂直越权访问管理员接口，系统成功返回 403 拦截；构造 `' OR '1'='1` 载荷验证了后端 MyBatis 预编译有效防御了 SQL 注入。
3. **自动化框架搭建**：利用 Pytest 的 `Fixture` 机制（`conftest.py`）封装了全局登录逻辑，实现 Token 的自动获取与全局复用，并集成 HTML 报告，大幅提升回归测试效率。
