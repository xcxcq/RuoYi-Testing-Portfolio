# 若依（RuoYi）后台管理系统 - 测试计划

## 1. 测试目的
本计划旨在验证若依后台管理系统（前后端分离版）的核心业务功能、权限控制（RBAC）及接口安全性，确保系统在上线前达到可交付的质量标准。

## 2. 测试环境
- **操作系统**：Windows 10/11
- **浏览器**：Chrome 最新版 (F12 开发者工具)
- **后端环境**：JDK 1.8+ / Spring Boot / MySQL 5.7+ / Redis
- **接口测试工具**：Apifox / Postman
- **自动化框架**：Python 3.10+ / Pytest / Requests

## 3. 测试范围
### 3.1 功能测试
- **登录认证模块**：正常登录、错误密码、验证码校验、Token 失效。
- **用户管理模块**：新增用户（必填项、格式校验）、修改用户、删除已分配角色的用户拦截。
- **角色管理模块**：角色分配、菜单权限绑定。
- **菜单管理模块**：菜单新增、隐藏、外链配置校验。

### 3.2 接口与安全测试
- **鉴权越权测试**：验证普通用户是否可通过 URL 或修改 Token 越权访问管理员接口。
- **SQL 注入防护**：验证查询接口是否对恶意注入载荷（如 `' OR '1'='1`）进行有效拦截。
- **并发防重测试**：验证新增接口在连续请求下是否具备幂等性。

## 4. 测试策略
1. **黑盒测试**：使用等价类划分、边界值分析、场景法设计测试用例。
2. **接口自动化**：使用 Python + Pytest 搭建自动化框架，实现登录态（Fixture）全局复用，并生成 HTML 测试报告。
3. **安全渗透**：通过抓包工具篡改请求参数和请求头，验证后端拦截机制。

## 5. 准入与准出标准
- **准入标准**：前后端环境部署完成，数据库初始化完毕，管理员账号可正常登录。
- **准出标准**：核心测试用例 100% 执行，致命/严重级别 Bug 修复率达到 100%，安全漏洞（越权/SQL注入）验证已完全防御。
